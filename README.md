# Belajar AI 30 Hari

Dokumentasi perjalanan belajar Ai dari nol selama 30 hari.

## Apa yang dipeljari

### Minggu 1 : Fondasi Python
- Variabel, tipe data, kondisi, perulanagan/looping, fungsi
- Dictionary dan list of dictionary
- Mini proyek: Sistem cek nilai siswa

### Minggu 2 : Library Data
- Numpy unutuk komputasi numerik
- Pnadas untuk pengelolaan data
- Matplotlib unutk visualisasi
- Membaca dan membersihkan file CSV

### Minggu 3 : Machine Learning
- Supervised learning : Regresi Linier dan KKN
- Train test split dan evaluasi model
- Confusion matrix, precision, recall
- Overvitting, undervitting, cross validation
- Decision Tree dan Random Forest
- NLP dan analisis sentimen

### Minggu 4 : AI Lanjuatan
- Neural Network dengan MLPClassifier
- Integrasi AI API (Groq)
- Sistem rekomendasi buku

## Tools yang digunakan
- Python 3
- Google collab
- Scikit-learn, Pandas, Numpy, Matplotlib
- Groq API

## Cara menjalankan
Semua kode bisa dijalankan di Google Colab tanpa instalasi apapun
